# 🛒 Amazon Clone (HTML & CSS)

A responsive Amazon homepage clone built using **HTML5 and CSS3**.

## 🚀 Features

* Amazon-like navigation bar
* Search bar UI
* Product grid layout
* Hero banner section
* Footer section
* Clean UI and layout
